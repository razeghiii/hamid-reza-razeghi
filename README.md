# نِگارسامانه تبلیغات

سامانه فارسی مدیریت تبلیغات متنی و بنری، با نصب‌کننده تحت وب، گزارش‌گیری نمایش/کلیک/تبدیل و رابط راست‌به‌چپ.

## اجرا

```bash
php -S localhost:8000
```

سپس `http://localhost:8000` را باز کنید. نصب‌کننده اطلاعات پایگاه‌داده SQLite و مدیر اولیه را دریافت می‌کند.

## امکانات

- مدیریت تبلیغ‌دهنده، ناشر، سایت و جایگاه تبلیغاتی
- کمپین‌های زمان‌بندی‌شده با بودجه و سقف روزانه
- تبلیغات متنی و گرافیکی و هدف‌گیری بر اساس سایت و جایگاه
- گزارش نمایش، کلیک، CTR، تبدیل و ارجاع موفق
- لینک رهگیری کلیک (`click.php`) و پیکسل نمایش (`impression.php`)
